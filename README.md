# Telegram Mini App для заказов официантов — Vercel

Меню открывается по адресу Vercel. FastAPI принимает заказы, проверяет Telegram `initData`, отправляет позиции в нужные рабочие чаты и пишет строку в Google Sheets. Бот получает `/start` через Telegram webhook; постоянно работающий polling-процесс не нужен.

## 1. Загрузите проект в GitHub

Создайте GitHub-репозиторий и загрузите **всё содержимое этой папки** в его корень. Там должны быть `index.py`, `requirements.txt`, `.python-version`, `public/` и `bot/`.

Не загружайте `.env` и JSON-ключ Google. Они уже исключены через `.gitignore`.

## 2. Подготовьте данные Telegram и Google

### Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и сохраните токен.
2. Создайте рабочие чаты бара, кухни и кальяна, добавьте туда бота с правом отправлять сообщения.
3. Узнайте числовые Telegram ID официантов и рабочих чатов.
4. В `@BotFather` выполните `/setdomain`, выберите бота и укажите его Vercel-домен без `https://` и пути, например `nightshift-orders.vercel.app`.

### Google Таблица

1. Создайте Google Таблицу.
2. В Google Cloud включите **Google Sheets API** и **Google Drive API**.
3. Создайте сервисный аккаунт и скачайте JSON-ключ.
4. Поделитесь таблицей с адресом `client_email` из ключа, роль — **Редактор**.
5. Скопируйте ID таблицы из ссылки, между `/d/` и `/edit`.

Приложение автоматически создаст лист `Заказы`. Не отправляйте ключ Google и токен бота посторонним.

## 3. Создайте проект Vercel и добавьте настройки

1. Откройте Vercel и выберите **Add New → Project**.
2. Импортируйте GitHub-репозиторий с этим проектом.
3. Оставьте Framework Preset как **Auto Detect** (или выберите **FastAPI**, если Vercel предложит его). Root Directory — корень репозитория.
4. До нажатия Deploy откройте **Environment Variables** и добавьте переменные для **Production**:

| Переменная | Что указать |
| --- | --- |
| `BOT_TOKEN` | Токен от BotFather |
| `STAFF_IDS` | Telegram ID официантов через запятую, например `123456789,987654321` |
| `WEB_APP_URL` | Адрес Vercel проекта, например `https://nightshift-orders.vercel.app` |
| `WEBHOOK_SECRET` | Случайная строка из латинских букв, цифр, `_` и `-`, минимум 32 символа |
| `BAR_CHAT_ID` | Числовой ID чата бара |
| `KITCHEN_CHAT_ID` | Числовой ID чата кухни |
| `HOOKAH_CHAT_ID` | Числовой ID чата кальянов |
| `TABLE_COUNT` | Количество столов, например `30` |
| `SPREADSHEET_ID` | ID Google Таблицы |
| `WORKSHEET_NAME` | `Заказы` |
| `GOOGLE_CREDENTIALS_JSON` | Весь текст JSON-ключа сервисного аккаунта |

`WEB_APP_URL` — адрес вашего проекта с Vercel. Выберите имя проекта `nightshift-orders`, если хотите получить адрес из примера. Если Vercel назначит другой адрес, исправьте переменную после создания проекта и сделайте **Redeploy**.

В `GOOGLE_CREDENTIALS_JSON` вставьте весь JSON, включая фигурные скобки. Все секреты вводите в Vercel, а не в GitHub.

Нажмите **Deploy**. Vercel публикует страницу из `public/` и автоматически запускает FastAPI-приложение из `index.py`; так устроен [официальный FastAPI deployment на Vercel](https://vercel.com/docs/frameworks/backend/fastapi).

## 4. Привяжите Telegram к Vercel

Команду настройки webhook нужно выполнить на компьютере один раз. Установите Python 3.12+, скачайте тот же репозиторий и откройте `cmd` в его корневой папке. Выполните:

```cmd
py -m venv .venv
call .venv\Scripts\activate.bat
py -m pip install -r requirements.txt
if not exist bot\.env copy .env.example bot\.env
```

Откройте `bot/.env` и вставьте туда значения из Vercel. Если вы уже создали этот файл раньше — не заменяйте его: сохраните текущие значения, измените `WEB_APP_URL` на адрес Vercel и добавьте новую строку `WEBHOOK_SECRET`. Для `GOOGLE_CREDENTIALS_JSON` локально можно оставить пустое значение: установщик webhook не обращается к таблице. Чтобы создать секрет webhook, можно выполнить команду и вставить её результат одновременно в `.env` и Vercel:

```cmd
py -c "import secrets; print(secrets.token_urlsafe(32))"
```

Теперь зарегистрируйте webhook:

```cmd
py -m bot.set_webhook
```

В ответе должно появиться `Webhook установлен: https://.../api/telegram/webhook`. После этого отправьте боту `/start` — он покажет кнопку открытия меню.

## 5. Проверьте заказ

1. Откройте `https://ваш-проект.vercel.app` — должна появиться страница меню.
2. В Telegram отправьте боту `/start` и нажмите кнопку.
3. Выберите стол и позиции из каталога, отправьте тестовый заказ.
4. Убедитесь, что заказ появился в Google Таблице, а блюда пришли в соответствующие рабочие чаты.

Если поменяли production-домен, повторите настройку webhook командой `py -m bot.set_webhook` с новым `WEB_APP_URL`.

## Меню и выручка

Меняйте список товаров и цены в `bot/catalog.py`, затем отправьте коммит в GitHub — Vercel автоматически обновит проект.

Лист `Заказы` содержит дату/время, официанта, Telegram ID, стол, состав заказа, сумму и ID заказа. Для суммы за смену укажите начало и конец периода в `Сводка!B1` и `Сводка!B2`:

```gs
=SUMIFS(Заказы!F:F;Заказы!A:A;">="&B1;Заказы!A:A;"<="&B2)
```

Число заказов за период:

```gs
=COUNTIFS(Заказы!A:A;">="&B1;Заказы!A:A;"<="&B2)
```

Если Google Таблицы ожидают запятые, замените `;` на `,`.
